# 📱 About the App

Suraksha-Setu is an Android application developed to improve women’s safety during emergencies and unsafe situations.  

The app allows users to instantly trigger SOS alerts, share live GPS location, send emergency SMS notifications, and activate loud alarm sounds for quick assistance.

This project focuses on providing fast emergency response and improving personal safety during night travel or isolated situations.

---

# 🎯 Problem Statement

Women and elderly citizens travelling alone often feel unsafe, especially during night hours or emergency situations. Traditional emergency systems may delay response or fail to notify trusted contacts quickly.

Suraksha-Setu solves this problem by providing:

- 🚨 Instant SOS triggering
- 📍 Live location sharing
- 📩 Emergency SMS alerts
- 🔊 Loud alarm activation
- ⚡ Quick emergency communication

This helps reduce response time and improve personal safety.

# 🚀 Getting Started

## Prerequisites

- Android Studio
- JDK 11+
- Android Emulator or Physical Device

---

## Clone Repository

```bash
git clone https://github.com/suhasmalur/Surakshasetu-v3.git
```

---

## Open Project

1. Open Android Studio
2. Click **Open**
3. Select the project folder
4. Wait for Gradle Sync

---

## Run Application

1. Connect Android Device or Start Emulator
2. Click ▶️ Run
3. App will install automatically
